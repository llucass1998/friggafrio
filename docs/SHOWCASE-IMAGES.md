# Showcase Images (Carrossel Principal)

As imagens desta pasta (`apps/storefront/public/images/showcase/`) são usadas no carrossel de produtos da Home.

## Dimensões Recomendadas
- 1600x1200 (Proporção 4:3)

## Formatos Suportados
- `.webp` (Recomendado)
- `.avif`
- `.png` (Se precisar de transparência real)

## Arquivos Esperados

| Nome do Arquivo | Conteúdo Esperado | Alt Text Recomendado |
| --- | --- | --- |
| `refrigerant-gases.webp` | Botijas de gases refrigerantes | "Diferentes tipos de gases refrigerantes" |
| `filter-driers.webp` | Filtros secadores de linha de líquido | "Filtros secadores para refrigeração" |
| `compressors.webp` | Compressores herméticos e scroll | "Compressores de refrigeração variados" |
| `cold-room.webp` | Painéis e evaporadores de câmara fria | "Instalação e componentes para câmara fria" |
| `professional-tools.webp` | Bomba de vácuo, manifold, flangeador | "Ferramentas profissionais para refrigeração" |
| `copper-and-insulation.webp` | Bobinas de cobre e tubos esponjosos | "Tubos de cobre e isolamento térmico" |

> **Nota para o cliente final:** 
> Enquanto as imagens reais não são fornecidas, componentes de UI no Frontend renderizam cores ou ícones placeholder.
> Assim que salvar os arquivos nesta pasta usando os nomes exatos listados acima, as imagens irão aparecer imediatamente no carrossel.
